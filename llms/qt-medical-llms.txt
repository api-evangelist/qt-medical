## What an agent can and cannot do here

QT Medical has **no public developer program**. As of 2026-08-26 there is no developer
portal, no API reference, no OpenAPI/AsyncAPI/GraphQL contract, no SDK in any public package
registry, no MCP server and no A2A agent card. `/llms.txt`, `/openapi.json` and every
`/.well-known/*` path return HTTP 404 on both `www.qtmedical.com` and
`dashboard.qtmedical.com`.

An API does exist and QT Medical says so on its own product page — "API available for EMR
integration*** (Extra fee)" — and the company also offers telehealth partners an **ADK** for
embedding ECG capture into their own mobile apps. Neither is self-serve: both are obtained
through the sales team, under contract, with no published documentation. The documented
default path for getting an ECG into an EMR is manual: "Completed ECG report available in
PDF for EMR."

**There is nothing here for an agent to call.** Do not construct requests against
`dashboard.qtmedical.com`; it is a Laravel web application serving a human sign-in page, not
a documented API. Route integration questions to sales.

## Products

- [PCA 500 12-lead ECG](https://www.qtmedical.com/en/products/PCA-500): compact wireless
  12-lead ECG recorder; 510(k) cleared 2018 (adult, non-acute incl. home), 2022 (infants,
  children, adolescents), February 2024 (acute care). Also CE, PMDA (Japan), TGA
  (Australia), Health Canada MDL.
- [QHeart Sensor](https://www.qtmedical.com/en/product-categories/Qheart-Sensor): patented
  single-use prepositioned electrode strip; QT Medical states it cuts lead-placement time by
  up to 70%.
- [Xpress ECG](https://www.qtmedical.com/en/products/XpressECG)
- QT ECG apps: iOS, Android and Windows desktop; connect to the recorder over Bluetooth and
  transmit to the cloud.
- [QTM Dashboard](https://dashboard.qtmedical.com/login): the cloud console (sign-in
  required).
